# Cafe Management System

A simple **Cafe Management System** built using **Python** to help manage orders, inventory, and billing in a cafe. This project is aimed at making cafe operations more efficient by providing a digital solution to handle customer orders and track sales.



## Features

- **Add / Remove Items**: Manage menu items easily.
- **Order Management**: Take customer orders and generate bills automatically.
- **Billing System**: Automatically calculates total amount with taxes.
- **Inventory Tracking**: Keeps track of available items.
- **User-Friendly Interface**: Console-based Python interface for simplicity.



## Technologies Used

- **Programming Language:** Python 3.x
- **Libraries:** 
  - `tkinter` (optional, for GUI)
  - `sqlite3` (optional, for database storage)
  - `os` (for file handling)
  - `datetime` (for timestamping orders)

## Usage

-Run the app.py file.
-Select options from the menu:
-Add new items to the menu
-Take customer orders
-Generate bills
-View sales reports
-Orders will be stored and total sales can be tracked.
